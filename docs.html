Dokumentasi & Tutorial Pengguna

Panduan singkat & langkah-langkah untuk menggunakan aplikasi Stock Gudang Produksi. Mudah diikuti untuk user dan admin.

Ringkasan singkat

Aplikasi ini membantu Anda mengelola stock gudang produksi (racking). Anda dapat menambah produk, mengelola status Hold/Release/Reject, menggunakan lookup settings, dan mengekspor data ke CSV.

Persiapan cepat (Quickstart)

  1. Buka index.html dan registrasi/login (Email & Password).
  2. Masuk ke Product Masuk untuk menambahkan item baru.
  3. Gunakan Kelola Product untuk melihat, update, hapus, dan export CSV.
  4. Atur pilihan seperti Block / Product di Input Setting.

Menambahkan product (langkah demi langkah)

  1. Buka Product Masuk (addproduct.html).
  2. Isi field: Block, Lantai, Product, Code, Tanggal Exp, Jumlah, Satuan, Cycle.
  3. Pilih Status:
    • Hold: produk ditahan hingga Hold Until habis (masukkan hari pada Hold Until).
    • Release: produk siap packing — Deskripsi otomatis menjadi Ready Packing.
    • Reject: produk ditolak; Hold Until akan diabaikan.
  4. Deskripsi: opsional, tapi bila pilih Release sistem akan menimpa Deskripsi menjadi "Ready Packing".
  5. Tekan Add Product. Jika sukses, form akan reset.
Catatan: Anda harus login untuk menambahkan product.

Kelola product (Dashboard)

Di Kelola Product Anda bisa:

  • Mencari produk dengan search bar (mencakup deskripsi dan tanggal).
  • Mengurutkan otomatis berdasarkan tanggal Exp (FIFO).
  • Mengupdate produk: klik tombol Update, ubah field pada modal lalu Save.
  • Hapus produk: tombol Out (akan meminta konfirmasi).
  • Export daftar ke CSV (hanya data yang sedang tampil / terfilter).

Perilaku khusus: kalau HoldUntil kadaluarsa client akan otomatis mengubah status menjadi Release dan men-set deskripsi menjadi Ready Packing.

Input Setting

Gunakan halaman Input Setting untuk menambah atau menghapus pilihan Block, Product, Lantai, atau Code. Hanya pengguna yang login dapat menambah/hapus.

Export CSV

Tekan tombol Export CSV di dashboard. File akan diunduh dengan nama products-YYYYMMDD.csv. Baris di-export sesuai data yang sedang tampil di tabel (filter/search berlaku).

Aturan penting & Deskripsi otomatis

  • Jika status dipilih Release (baik saat create maupun update), sistem otomatis mengisi deskripsi = "Ready Packing".
  • Jika status Hold dan holdUntil telah lewat, aplikasi client mengubah status menjadi Release dan juga set deskripsi menjadi "Ready Packing".

Troubleshooting cepat

  • Permission denied (Firestore): pastikan Anda sudah login dan rules Firestore sesuai; cek pesan error di console.
  • Service worker tidak aktif: jalankan via server lokal (tidak berjalan di file://). Lakukan hard-refresh atau unregister SW bila perubahan tidak muncul.
  • CSV kosong: pastikan ada produk yang dimuat; tekan Load more jika perlu.

FAQ singkat

Apa itu Hold Until?
Jumlah hari produk di-hold sejak hari ini. Setelah habis, produk akan auto-release (jika masih hold).
Mengapa Deskripsi berubah menjadi Ready Packing?
Ini aturan bisnis: produk berstatus Release dianggap siap packing.
